GAME RULES

Game format
NBA 4×12 · FIBA 4×10 · NCAAM 2×20. Overtime is 5 min.
Min. sample (min)
No OVER/UNDER signal until this much game time has been played.
Live-pace weight
Higher trusts live pace sooner; lower leans on the book line longer. 50 is balanced.
Late-game guard
Warns in the last 2 minutes, when fouling and garbage time distort pace.
